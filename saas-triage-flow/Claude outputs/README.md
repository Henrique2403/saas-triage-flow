# Agiliza Triagem — Documentação

Totem digital de triagem inicial para unidades do SUS (UBS, pronto-atendimento). O paciente informa sintomas e histórico, o totem mede sinais vitais com sensores integrados e o sistema encaminha para o especialista disponível, respeitando a prioridade do protocolo (Manchester/GBCR).

## Próximos passos (resumo)

1. Fazer 20+ entrevistas com diretores e enfermeiros antes de escrever código de produto
2. Conseguir um advisor/mentor da área de saúde
3. Contatar GBCR e CFM/COFEN para validar protocolo e orientação regulatória
4. Tratar LGPD e normas do CFM desde o primeiro dia
5. Desenvolver o MVP em ~3 meses
